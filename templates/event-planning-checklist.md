# Event Planning Checklist (TEMPLATE)

Tick items as you go. Delete what does not apply.

## Strategy

- [ ] Goal and success measures written down
- [ ] Audience and expected size
- [ ] Date, time zone, and format confirmed (check clashes with holidays and exams)
- [ ] Budget approved ([template](event-budget-template.csv))

## People

- [ ] Speaker(s) invited, confirmed, and briefed
- [ ] Volunteers recruited and briefed
- [ ] Host / moderator named
- [ ] Conduct-report contact named

## Logistics

- [ ] Platform or venue booked and tested
- [ ] Registration page live
- [ ] Accessibility: captions, slides shared, access needs question
- [ ] Run-of-show written and rehearsed
- [ ] Backup plans for speaker, platform, and host

## Communications

- [ ] Comms calendar created ([template](event-comms-calendar-template.csv))
- [ ] Invitation, reminders, and day-of messages drafted
- [ ] Code of conduct linked

## During the event

- [ ] Recording consent announced (if recording)
- [ ] Attendance captured
- [ ] Questions logged
- [ ] Feedback link shared

## After the event

- [ ] Thank-yous sent to speakers and volunteers
- [ ] Feedback survey sent within 24 hours
- [ ] Attendance data cleaned and report run ([script](../scripts/event_report.py))
- [ ] [Post-event report](post-event-report-template.md) written
- [ ] Materials shared; retrospective held; playbook updated
