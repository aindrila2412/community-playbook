# Event Playbook (TEMPLATE)

> Template using a **fictional sample event** ("Example Learners Club: Study Session"). It is a general planning aid, not a record of any real event I ran for an employer or client.

## 1. Define the event

| Item | Sample (fictional) |
|---|---|
| Goal | Give members a focused, friendly session to learn a skill together |
| Audience and size | Beginners; 30 to 60 expected |
| Format | Online, 90 minutes, one talk plus breakout practice |
| Success measures | Registrations, attendance rate, feedback rating, follow-up actions |
| Owner / team | Lead organiser, two volunteers, one host |

## 2. Timeline

| When | Task | Owner |
|---|---|---|
| T-8 weeks | Confirm goal, date, format, budget | Lead |
| T-7 weeks | Recruit speaker(s) and volunteers | Lead |
| T-6 weeks | Open registration; first announcement | Comms |
| T-4 weeks | Confirm agenda, speaker brief, accessibility needs | Lead |
| T-2 weeks | Reminder 1; tech check scheduled; run-of-show drafted | Comms / Tech |
| T-1 week | Reminder 2; final run-through; volunteer briefing | Lead |
| T-1 day | Reminder 3; materials uploaded; backup plan confirmed | Comms |
| Event day | Run the event | All |
| T+1 day | Thank-you and feedback survey | Comms |
| T+1 week | Post-event report; recordings and materials shared | Lead |
| T+2 weeks | Retrospective; update this playbook | Lead |

## 5. Run-of-show (sample, 90 minutes)

| Time | Segment | Lead |
|---|---|---|
| 0:00 | Welcome, code of conduct, housekeeping | Host |
| 0:05 | Talk | Speaker |
| 0:40 | Breakout practice | Volunteers |
| 1:10 | Q&A | Host and speaker |
| 1:25 | Thanks, feedback link, next event | Host |

## 6. Inclusion and safety

- Share the [code of conduct](../docs/code-of-conduct-and-moderation.md) in the invitation and at the start.
- Captions on; slides shared beforehand; ask about access needs at registration.
- Name a person to receive conduct reports during the event.

## 7. Contingency

| Risk | Plan |
|---|---|
| Speaker drops out | Backup speaker or recorded session |
| Platform fails | Alternative link ready; message prepared |
| Low registration | Extra reminder; ask partners to share |
| Disruptive attendee | Mute/remove per the moderation ladder; log it |
